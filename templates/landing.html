Data Pipeline

01
RSS News Ingestion Financial headlines pulled from live feeds via feedparser — up to 20 articles per query on NIFTY, SENSEX, or any ticker.
02
FinBERT NLP Analysis Hugging Face Transformers running ProsusAI/finbert classifies each headline into Positive, Negative, or Neutral with a confidence score.
03
yfinance Price Correlation 60-day historical OHLCV data fetched for the ^NSEI index and aligned with daily sentiment scores to build the training dataset.
04
Logistic Regression Model Scikit-learn Logistic Regression trained on sentiment-price pairs. Model persisted to models/sentiment_model.pkl.
05
Flask Dashboard Live predictions, Matplotlib distribution charts, and a headline table — served on port 5000 via Docker.
