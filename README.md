# NewsSense

NewsSense is an AI-powered financial sentiment analysis dashboard that combines real-time financial news with live stock market data to generate market sentiment insights.

## Features

* Real-time financial news ingestion via RSS feeds
* Live market data integration using Yahoo Finance API
* Financial sentiment classification using FinBERT
* Sentiment visualization and analytics dashboard
* Correlation of news sentiment with stock price movements

## Tech Stack

* Python
* Flask
* Hugging Face Transformers
* FinBERT
* Pandas
* Scikit-learn
* Matplotlib
* Yahoo Finance API (yfinance)

## Project Overview

The system collects financial news, performs NLP-based sentiment analysis, and provides investors with actionable insights by mapping sentiment trends against market behavior.
